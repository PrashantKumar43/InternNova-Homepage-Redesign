# InternNova Homepage Redesign — Student Concept Project

A responsive homepage concept built with **HTML5, CSS3, and vanilla JavaScript**.

## Files
- `index.html` — semantic page structure and homepage content
- `style.css` — responsive layout, colors, cards, and motion
- `script.js` — mobile navigation, FAQ accordion, reveal-on-scroll, and footer year

## Run locally
1. Extract this folder.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension in VS Code.

No build tools or package installation are required.

## Before submitting
- Review the live official InternNova site and adjust the concept if the current brand/content changes.
- Test the page at desktop, tablet, and mobile widths.
- Check all external links and replace any content that your mentor asks you to change.
- Publish the folder to a GitHub repository and deploy the site (for example, with GitHub Pages or Vercel).
- Capture screenshots of desktop and mobile layouts.

## Notes
This is an independent student redesign concept, not an official InternNova website. Program names and contact links point to the official website for verification. The learner-story cards describe general learning themes and are not presented as direct testimonials.
